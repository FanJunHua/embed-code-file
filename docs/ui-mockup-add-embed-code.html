3 设计说明与审批点


  

    
UI 字段对应 README 属性行为

    

      代码来源PATH 前缀
      Vault 文件 → vault://…；远程 → http(s)://…（与插件渲染器的两种来源一致）
    

    

      文件路径 / URLPATH
      Vault 模式输入即模糊搜索库内文件；远程模式提示使用 raw 链接
    

    

      语言围栏标记 embed-<lang>
      下拉选项来自设置页 Included Languages
    

    

      行范围LINES
      支持 2,9,30-40 组合；留空嵌入全部行
    

    

      标题TITLE
      留空则省略该行，渲染时自动回退为 PATH（与 README 行为一致）
    

  


  
实现要点（批准后开发）

  
    
    
  • 右键菜单：监听 Obsidian editor-menu 事件，仅在 Markdown 编辑器中注册「Add embed-code」菜单项（图标 code-glyph）。
    • 
    
  • 弹窗：Obsidian Modal 子类；样式使用主题 CSS 变量（--background-primary / --interactive-accent 等），自动适配亮暗主题。
    • 
    
  • 预填：从菜单进入时若有选区，LINES 预填为选区行号范围；PATH 若光标处恰为路径/URL 文本则尝试识别（增强项，可裁剪）。
    • 
    
  • 生成块省略空字段（TITLE/LINES），插入时用 editor.replaceSelection 写入光标处，前后补空行。
    • 
    
  • 构建产物按 AGENTS.md 约定输出至 output/embed-code-file/（main.js、manifest.json、styles.css）。
    •
