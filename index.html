Embed Code File

Obsidian Plugin

在 Obsidian 笔记中嵌入代码文件——来自 vault 或远程（如 GitHub），支持行选、标题与行号显示。

⭐ FanJunHua/embed-code-file v1.3.0 · 已发布 行号显示 · 开发中

1核心用法

在代码围栏标记前加 embed- 前缀，并用 YAML 键值对声明来源与选项（PATH 必填，LINES / TITLE 可选）。

语法

```embed-<lang>
PATH: "vault://<path-to-code-file>"
LINES: "2,9,30-40"
TITLE: "Some title"
```

示例 · vault 本地文件

```embed-cpp
PATH: "vault://Code/main.cpp"
LINES: "2,9,30-40"
TITLE: "QuickSort core"
```

示例 · 远程文件（GitHub raw）

```embed-ts
PATH: "https://raw.githubusercontent.com/FanJunHua/embed-code-file/v1.3.0/main.ts"
LINES: "30-40"
TITLE: "main.ts (remote)"
```

默认语言

默认登记：c,cs,cpp,java,python,go,ruby,javascript,js,typescript,ts,shell,sh,bash。可在设置页 Included Languages 自定义增删。

2右键快速添加v1.3.0 已发布

在 Markdown 编辑区内点击右键，选择 Add embed-code 打开添加弹窗——不用手写 YAML。

来源分段切换

📁 Vault 文件 / ☁️ 远程 URL 一键切换；远程提示使用 raw 链接。

模糊搜索 Top 20

输入即搜库内文件，按匹配度降序取前 20 条（v1.3.0 修复排序）。

自动补 vault:// 前缀

选中或输入文件路径自动携带 vault://，无需手打。

扩展名自动匹配语言

选中文件后按扩展名匹配语言：.cpp→cpp、.ts→typescript、.py→python、.sh→bash 等；无匹配保持当前选择。

LINES 选区预填与组合

从菜单进入时选区行号自动预填（如 5-12）；支持 2,9,30-40 组合；留空 = 全部行。

TITLE 留空回退

TITLE 留空则整行省略，渲染时回退显示 PATH。

实时插入预览

弹窗底部实时展示将插入光标处的完整代码块（前后补空行）。

3行号显示🚧 开发中 · 下个版本

开发中（Coming soon）：以下为阶段三规划的交互示意，当前版本尚未包含该功能；演示效果不代表已发布行为。

设置页将新增下拉（三种模式）：

对照：LINES: "56-58"（源文件 main.cpp）

🚧 开发中 
main.cpp...56int fib(int n) {57    return n < 2 ? n : fib(n-1) + fib(n-2);58}...

显示原行号 → 56 / 57 / 58

🚧 开发中 
main.cpp...1int fib(int n) {2    return n < 2 ? n : fib(n-1) + fib(n-2);3}...

显示新行号 → 1 / 2 / 3

  • ... 省略行不编号、不占号（行号单元格留空）。
  • 多段 LINES（如 25,34,45-76）新行号跨段连续计数。
  • 仅对 embed-<lang> 块生效；普通代码块与 Obsidian 原生行为不受影响。
  • 阅读视图与 live preview 均生效；配色走 Obsidian CSS 变量，浅色/深色主题自动适配。

4特性总览

本页右上角可切换浅色 / 深色主题预览——实际实现使用 Obsidian 主题 CSS 变量，自动跟随当前库主题。
